# Chrome extension tutorial

This is a study folder for [Chrome Extension Tutorial (2026): Build & Publish with Manifest V3](https://www.youtube.com/watch?v=EYbWVXTF-hA)

## Notes

* To test the extension
  * On Chrome, visit `chrome://extensions`, enable the `developer mode` at the top right, then click on `load unpacked` and open this folder.
  * On Firefox, open the `about:debugging` page, click `This Firefox`, then `Load Temporary Add-on`, and select any file in the extension's directory. The extension installs and remains installed until Firefox is restarted.
* According to [Firefox extension: Your first extension](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Your_first_WebExtension):

  > `browser_specific_settings` is required by Firefox.
